# Bazaar Decor Presets

『牧場物語 Let's！風のグランドバザール』のバザールオブジェの配置を、6つのプリセットとして保存・読み込みできるModです。加工品用・料理用など、実効果に合わせた配置を切り替えられます。

読み込みはオブジェ変更画面の**未確定の編集配置**へ反映されます。最後の確定・取消はゲーム標準の操作で行います。Modがゲームセーブや実効果データへ直接書き込むことはありません。

## 導入

BepInEx（IL2CPP版）が導入されている環境で使用します。ゲーム終了後、次の構成で配置してください。

```text
BepInEx/
└─ plugins/
   └─ BazaarDecorPresets/
      ├─ BazaarDecorPresets.dll
      └─ i18n/
         ├─ ja.json
         └─ en.json
```

ソースからビルドする場合、DLLとi18nフォルダは `BazaarDecorPresets/bin/Release/net6.0/` に出力されます。ゲーム本体やBepInExの参照DLLを同梱する必要はありません。

## 操作

通常の「オブジェの変更」画面で、フッターの **＋「プリセット」** を押すと「プリセットを保存」「プリセットを読み込み」「やめる」のメニューが開きます。キーボードでは画面に表示される対応キーを使用してください。以下のA/B/Yはゲームパッドのガイド表記です。

### 保存

1. 「プリセットを保存」を選びます。
2. 6つの保存先から1つを選びます。右側には、保存対象の現在の編集配置が表示されます。
3. ゲーム標準の名前入力画面で名前を入力します（最大8文字、日本語入力対応）。
4. 名前確認で確定すると保存されます。使用済みスロットを選んだ場合は上書きされます。
5. 完了ダイアログを閉じると「オブジェの変更」画面へ戻ります。

名前入力をBで取り消すと、保存せず保存先一覧へ戻ります。名前確認からBで戻ると名前を入力し直せます。

保存するのは**その時点の編集配置**です。その後ゲーム側の編集を取り消しても、保存したプリセットは残ります。

### 読み込み

1. 「プリセットを読み込み」を選びます。
2. スロットを選ぶと、右側に保存済みのオブジェ一覧が表示されます。
3. Aで決定すると、配置枠・アイテム・所持数などを検証してから読み込み、全カテゴリの3D表示を更新します。
4. 完了ダイアログを閉じると「オブジェの変更」画面へ戻ります。
5. ゲーム標準の操作で配置を確定してください。変更を取り消す場合は、ゲームの終了確認に従って反映せずに戻ります。

空きスロットでAを押しても読み込みや画面遷移は行わず、選択音だけが鳴ります。

### 削除・戻る

- 保存・読み込みどちらの一覧でも、保存済みスロットでYを押すと、プリセット名つきの削除確認が開きます。削除完了後は一覧へ戻ります。
- 一覧の「やめる」またはBで、保存／読み込みを選ぶメニューへ戻ります。
- 保存・読み込み・削除の完了ダイアログはA/Bで閉じられます。
- プリセット操作終了後は、通常のタイトルとフッターへ戻ります。Yによる公式の店舗情報確認も通常どおり使用できます。

## Bazaar Decor Transmogとの併用

単独でも使用できます。Bazaar Decor TransmogのAPI対応版（0.9.171以降、公開API v1）との併用では、みため変更中にPresets側の入口とガイドを非表示にします。Transmog側のプリセット操作は維持され、保存データは共有しません。

APIのない旧版では日英のタイトル判定に限られるため、API対応版を推奨します。APIの読み取りに失敗した場合は、Presetsの起動を停止して警告を記録します。

## 保存ファイル・バックアップ・撤去

プリセットは次のファイルに保存します。拡張子は `.cfg` ですが、中身はJSONです。

```text
BepInEx/config/BazaarDecorPresets.cfg
BepInEx/config/BazaarDecorPresets.cfg.bak
```

更新時の前回内容を `.bak` に残します。保存中は一時ファイル `.tmp` を使い、通常の成功・失敗後は削除します。強制終了や削除失敗時には残る場合があります。旧ファイル名からの自動移行は行いません。

撤去する場合はゲーム終了後、`BepInEx/plugins/BazaarDecorPresets` フォルダと、上記のMod専用データ（残っていれば `.tmp` も）を外してください。ゲーム標準の操作で確定した装飾配置は残ります。変更したい場合はゲーム内のオブジェ変更で編集してください。

## 問題が起きた場合

- 保存ファイルを読み取れない場合は、既存ファイルを上書きせず保存を停止します。
- 読み込み前の検証に失敗した場合、配置は変更しません。適用途中で失敗した場合は、読み込み直前の配置への復元を試み、結果を照合します。
- 「配置を元に戻せませんでした」と表示された場合は、確定せずゲーム標準の操作でオブジェ変更を取り消してください。
- 想定外のUI例外では、その編集セッションのプリセット機能を停止します。通常のオブジェ変更画面を閉じて開き直すと再試行できます。公式API自体が失敗する状況での完全な復帰は保証できません。

ログは `BepInEx/LogOutput.log` に出力します。不具合報告には、操作手順・画面の状態とともに、**ゲームを再起動する前のログ**を保存してください。起動情報・互換性情報・警告・エラーを記録し、開発用の詳細な診断トレースは出力しません。

## 翻訳

日英のJSONを同梱しています。文言はDLLと同階層の `i18n` から読み、選択言語のJSON → 英語JSON → DLL内蔵英語の順に取得します。欠損・破損ファイルやnull・空白の値はフォールバックし、フォルダを読めない場合も内蔵英語を使用します。

翻訳を追加する場合は、`en.json` をもとに、ゲームの言語識別子に対応するファイル名でJSONを作成してください（例：`ja.json`、`en.json`）。キーと `{0}` などの置換記号は維持します。オブジェ名や公式の操作ラベルはゲーム側の翻訳を利用します。

## 開発・検証

ゲームおよびBepInExの参照DLLを使用します。標準と異なる場所にゲームを導入している場合は、ビルド時に `GameDir` を指定してください。

```powershell
dotnet build .\BazaarDecorPresets.slnx -c Release
dotnet run --project .\tests\PresetChecks\PresetChecks.csproj -c Release
```

現在の自動チェックは84項目です。保存形式・6スロット・原子的保存とバックアップ・I/O失敗時の保全、配置検証・適用失敗と復元照合、例外時の後片付け、名前入力の終了処理、古い／重複コールバックの排除、翻訳フォールバック、プレビューのカテゴリ対応を検証します。

自動チェックはUnity上のUIや入力を実行しません。変更時は、保存・読み込み・削除と各画面の戻る操作、タイトル／フッター復帰、全カテゴリの表示更新、公式の確定・取消、再表示、Transmog併用／単独動作を実機で確認してください。

設計・調査・変更履歴は `docs/` にまとめています。
