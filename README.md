# Bazaar Decor Presets

バザール装飾の実効果プリセットModです。標準のオブジェ変更画面から、現在の編集配置を保存・読み込みできます。

プリセットの読み込みは編集画面へ反映されます。最後にゲーム標準の「決定」で確定するまでゲームセーブには書き込まれず、「やめる」で編集開始時の配置に戻せます。

## 導入

ゲーム終了後、`BazaarDecorPresets/bin/Release/net6.0` の内容を、ゲームの `BepInEx/plugins/BazaarDecorPresets` にコピーします。DLLと同階層の `i18n/ja.json`・`i18n/en.json` も必要です。依存DLLは不要です。

## 操作

通常の「オブジェの変更」画面を開き、画面下部の **＋「プリセット」** で標準プリセットメニューを表示します。確認用のF8操作は廃止しました。

BazaarDecorTransmogの公開API v1が利用できる場合、言語に依存せず、みため変更中の起動とガイド表示を抑止します。Transmog未導入でも単独で動作します。APIのない旧版では日英タイトル判定に戻るため、併用にはAPI対応版（0.9.171以降）を推奨します。APIの読み取りに失敗した場合は起動を停止して警告を記録します。

1. `プリセットを保存` を選ぶ。メニューは「プリセットを保存」「プリセットを読み込み」「やめる」の3択です。
2. 6つの保存先から1つを選ぶ。
3. ゲーム標準の文字入力画面で、たとえば `料理用` と入力して確定する。
4. 完了通知後、同じ一覧でスロット名が `1：料理用` のように表示されることを確認する。

`プリセットを読み込み` は、保存内容と現在の編集枠数・ゲーム公式の所持判定を確認してから編集画面へ反映します。最後にゲーム標準の「決定」で確定してください。

通常の装飾変更を行った際は、Modが自分の編集セッションに限り `SetCustomParts`、モデル読込、バフ再計算、効果取得の順序を `BepInEx/LogOutput.log` へ記録します。この診断はログ出力だけで、ゲームのメソッドを呼び直したり、結果を変更したりしません。

日本語IME、キーボード、ゲームパッド、取消操作をこの標準入力画面で確認してください。入力を取り消した場合、保存先一覧へ戻り、データは変わりません。

## 保存と撤去

プリセットは `BepInEx/config/com.icy.bazaardecorpresets.presets.json` に保存します。更新時の前回内容は `.bak` として残します。

ゲーム終了後にDLL・`i18n`フォルダ・このJSON・`.bak`を外せば、Mod由来の機能とデータは取り除けます。保存済みの装飾配置はゲーム標準のデータとして残るため、変更したい場合はゲーム内のオブジェ変更で編集してください。

JSONを読み取れない場合は既存ファイルを上書きせず、保存を停止して `LogOutput.log` に `BDP PresetFileError` を記録します。

## 確認してほしいこと

- 画面を開いた直後から＋「プリセット」が表示され、＋でメニューが開くか。メニューを閉じた後にも＋ガイドが戻り、再度開けるか。F8では開かないか
- `料理用` など日本語を直接入力・確定できるか
- B/Escで入力を取り消し、保存されないか
- 保存後に確認メニューでスロット名が表示されるか
- 読み込みでカテゴリ別の配置数が表示され、閉じても店舗モデル・効果・現在の編集配置が変わらないか
- 通常の装飾編集を確定・取消しても、Mod操作をしていない配置が変わらないか

診断ログを取る場合は、装飾編集画面でテントなどを1枠だけ変更して通常どおり確定または取消してください。ゲーム終了後、該当操作前後を含む `BepInEx/LogOutput.log` を確認します。

ゲーム終了後に `BepInEx/LogOutput.log` を保存しておくと、次の実配置読込段階を安全に進められます。

## 翻訳

文言はDLLと同階層の `i18n` フォルダから読みます。ゲームの言語名と同じJSONを追加すれば翻訳を増やせます。該当言語のファイルまたはキーがない場合は英語を使い、JSONの読込に失敗してもModは通常どおり起動します。

## 開発確認

`dotnet build .\BazaarDecorPresets.slnx -c Release` と、`tests/PresetChecks` の24項目を通しています。保存形式、固定6スロット、旧形式の移行、原子的保存とバックアップを確認します。ゲーム内UI・入力は実機確認が必要です。
