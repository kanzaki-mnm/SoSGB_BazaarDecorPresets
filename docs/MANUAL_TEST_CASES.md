# Bazaar Decor Presets 実機テストケース

リリース候補版をゲーム上で確認するためのチェックリストです。自動チェックでは確認できないUnity UI、入力、3D表示、ゲーム標準の確定・取消を対象にします。

## 実施前の準備

- [x] ゲームを終了する
- [x] 使用する `BazaarDecorPresets.dll` と `i18n/ja.json`・`en.json` を配置する
- [x] `BepInEx/config/BazaarDecorPresets.cfg` と `.bak` がある場合は、別フォルダへコピーして退避する
- [x] テストに使う配置をゲーム内で確認し、現在の装飾を失って困らないセーブデータで実施する
- [x] 異常系を行う場合は、普段使っているプリセットファイルではなくテスト用コピーを使用する

不具合が起きた場合は、ゲームを再起動する前に次を保存します。

- `BepInEx/LogOutput.log`
- 発生直前からの操作手順
- 画面のスクリーンショットまたは録画
- 使用した `BazaarDecorPresets.cfg`（共有して問題ない場合）

## 判定記号

- `[x]`：合格
- `[ ]`：未実施
- `[-]`：今回の構成では対象外

## 1. 最短スモークテスト

この節がすべて合格すれば、基本的な保存・読み込み・終了操作が機能しています。

### SMK-01 起動と入口

- [x] ゲームを起動し、BepInExのロードエラーがない
- [x] 通常の「オブジェの変更」画面を開く
- [x] 画面を開いた直後からフッターに `＋ プリセット` が表示される
- [x] ＋を押すと「プリセットを保存」「プリセットを読み込み」「やめる」が表示される
- [x] Yは公式の「店舗情報を確認」として動作する

期待結果：プリセットメニューが一度で開き、公式のA/B/Y・タブ操作を妨げない。

### SMK-02 保存

1. テントを含む複数カテゴリを、現在の確定配置とは違う組み合わせにする。
2. `プリセットを保存` → 空きスロットを選ぶ。
3. 日本語名 `料理用` を入力して確定する。
4. 名前確認で「はい」を選ぶ。
5. 保存完了ダイアログをAで閉じる。

- [x] タイトルが操作中は「プリセットを保存」になる
- [x] 右側の一覧が現在の編集配置と一致する
- [x] `料理用` を入力でき、名前確認文にも表示される
- [x] 「保存が完了しました。」が表示される
- [x] 完了後に「オブジェの変更」へ戻り、通常のタイトルと `＋ プリセット` が復帰する

### SMK-03 読み込みと3D表示

1. SMK-02とは異なる配置へ手動で変更する。
2. `プリセットを読み込み` → `料理用` を選ぶ。
3. 読み込み完了ダイアログをBで閉じる。

- [x] 一覧右側の名前・アイコン・空欄（`—`）が保存内容と一致する
- [x] 「読み込みが完了しました。」が表示される
- [x] ダイアログを閉じた直後、タブを切り替えなくても全カテゴリの3Dモデルが保存内容へ更新される
- [x] 読み込み後もカーソル、タブ、A/B/Yが操作できる

### SMK-04 ゲーム標準の確定

1. SMK-03の読み込み後、ゲーム標準の「決定」で配置を確定する。
2. 「オブジェの変更」を閉じ、もう一度開く。

- [x] 読み込んだ配置が確定されている
- [x] 再表示後も `＋ プリセット` が表示され、メニューを開ける

## 2. 保存フロー

### SAV-01 空きスロット表示

- [x] 6スロットすべてに `1：空きスロット` のような番号が表示される
- [x] 空きスロットをAで選ぶと名前入力へ進む
- [x] 選択中の行に対応したオブジェ一覧が表示される

### SAV-02 名前入力の取消

1. 空きスロットを選び、名前入力欄で文字を入力する。
2. 入力欄にカーソルがある状態でBを押す。
3. 再度名前入力へ進み、今度は「決定」にカーソルを合わせてBを押す。

- [x] どちらも保存先一覧へ戻る
- [x] 入力した名前は保存されない
- [x] 背景のオブジェ変更画面が閉じない
- [x] 暗転したままにならず、その後も操作できる

### SAV-03 名前確認から戻る

1. 名前を入力して「決定」を押し、名前確認画面を表示する。
2. 「名前を変える」またはBで入力画面へ戻る。
3. 名前を変更して保存する。

- [x] 確認文が `プリセット名「名前」で保存しますか？` になる
- [x] ペット名に関する文言が表示されない
- [x] 入力画面へ戻って名前を変更できる
- [x] 最後に確定した名前だけが保存される

### SAV-04 上書き

1. 保存済みスロットを選び、別名・別配置で保存する。

- [x] 選択した1スロットだけが新しい内容になる
- [x] 他のスロットは変化しない
- [x] `.bak` に更新前のファイルが残る

### SAV-05 完了ダイアログ

- [x] 保存完了ダイアログをAで閉じられる
- [x] 別の保存ではBでも閉じられる
- [x] どちらも通常画面へ戻り、タイトルとフッターが復帰する

## 3. 読み込みフロー

### LOD-01 空きスロット

- [x] 選択音だけが鳴る
- [x] ダイアログや通知は表示されない
- [x] 一覧に留まり、その後も操作できる

### LOD-02 読み込み後にゲーム標準の取消

1. 編集開始時の配置を覚える。
2. 異なるプリセットを読み込む。
3. ゲーム標準の終了操作で「反映しないでもどる」を選ぶ。
4. もう一度「オブジェの変更」を開く。

- [x] 編集開始時の配置へ戻っている
- [x] 読み込んだ配置がゲームセーブへ確定されていない
- [x] 保存済みプリセット自体は残っている

### LOD-03 所持品・枠の事前検証

所持していないオブジェを含むプリセット、または現在利用できない枠を含むプリセットを用意できる場合に実施します。

- [x] 読み込みが拒否される
- [x] 「読み込みできませんでした。配置は変更していません。」が表示される
- [x] 読み込み前の編集配置と3D表示が変化しない
- [x] 通知を閉じた後も一覧または通常画面を操作できる

### LOD-04 プリセット内容と一覧

- [x] テント1、棚3、小物4、大物3の全11枠が正しい順序で表示される
- [x] 空の枠はカテゴリ記号を保ち、名前は `—`、オブジェアイコンは非表示になる
- [x] スロットを上下に移動すると、右側の一覧が選択したプリセットへ更新される
- [x] 一覧を閉じる瞬間に左側パネルが中央へ飛ばない
- [x] 再度一覧を開いても左右の配置が崩れない

## 4. 削除と画面遷移

### DEL-01 削除の取消

1. 保存済みスロットでYを押す。
2. 削除確認をBまたは「やめる」で閉じる。

- [x] `プリセット「名前」を削除しますか？` と対象名が表示される
- [x] オブジェ一覧が削除確認へ重ならない
- [x] 取消後も対象プリセットが残る
- [x] 一覧へ戻り、操作を続けられる

### DEL-02 削除の確定

1. 保存済みスロットでYを押し、削除を確定する。

- [x] 「削除が完了しました。」が表示される
- [x] 完了ダイアログをAで閉じられる
- [x] 一覧へ戻り、対象行が番号つきの空きスロットになる
- [x] 他のプリセットは変化しない

### DEL-03 空きスロットのY

- [x] 空きスロットでYを押しても削除確認は開かない
- [x] 選択音以外の副作用がなく、一覧を操作し続けられる

### NAV-01 戻る経路

- [x] メインメニューの「やめる」／B → オブジェ変更画面
- [x] 保存先一覧の「やめる」／B → プリセットメニュー
- [x] 読み込み一覧の「やめる」／B → プリセットメニュー
- [x] 名前入力のB → 保存先一覧
- [x] 削除確認のB → 元の一覧
- [x] 各経路の後でタイトル、フッター、入力が正しい

## 5. 入力・再表示・連続操作

### INP-01 B連打耐性

配置を変更していない場合と、変更済みの場合の両方で実施します。

1. 名前入力の「決定」を押した直後から、名前確認への遷移中を含めてBを数回押す。
2. 名前確認と名前入力の間でもBを数回押す。

- [x] 背景にゲーム標準の終了確認が開かない
- [x] フィールドへ戻る暗転が始まらない
- [x] 暗転から戻らない状態にならない
- [x] タイトルや `＋ プリセット` が失われたままにならない
- [x] 保存先一覧へ戻るか、前面の名前入力／確認画面だけが正常に反応する

※手やコントローラーを痛めるほど連打する必要はありません。数回の素早い入力で十分です。

### INP-02 通常入力の復帰

プリセット操作を終了した後に確認します。

- [x] Aで通常のオブジェを選択できる
- [x] Bでゲーム標準の終了確認を開ける
- [x] Yで店舗情報を確認できる
- [x] L/Rまたは相当入力でカテゴリを切り替えられる
- [x] ＋で再度プリセットメニューを開ける

### INP-03 再表示

1. プリセットメニューを開閉する。
2. 「オブジェの変更」画面を閉じて開き直す。
3. 可能であれば別シーンへ移動して戻り、再度開く。

- [x] 毎回、画面表示直後から `＋ プリセット` がある
- [x] メニュー・一覧・プレビューが各1つだけ表示される
- [x] 前回のタイトル、選択、ダイアログ、入力不能状態が残らない

## 8. 保存ファイルの安全性（任意・ゲーム終了中に準備）

この節では必ずテスト用のプリセットファイルを使います。普段の `.cfg` と `.bak` は先に退避してください。

### ERR-01 破損したプリセットファイル

1. ゲームを終了する。
2. JSONではないファイルを `BepInEx/config/BazaarDecorPresets.cfg` として配置する。
3. ゲームを起動して保存一覧を開き、空きスロットを選ぶ。

- [x] ゲームと通常のオブジェ変更画面は操作できる
- [x] スロットは安全な空表示になり、フリーズしない
- [x] 保存時に「プリセットデータを読み取れないため保存できません」と表示される
- [x] 破損ファイルが別内容で上書きされない
- [x] `LogOutput.log` に `BDP PresetFileError` が記録される

確認後はゲームを終了し、テストファイルを外して退避したファイルを戻します。

### ERR-02 不正なItemId

1. ゲームを終了する。
2. テスト用 `.cfg` の保存済み枠1つの `ItemId` を `999999` など存在しない値へ変更する。
3. ゲームを起動し、そのプリセットを読み込む。

- [x] 読み込み前の一覧で不正値が通常オブジェとして確定扱いされない
- [x] 「読み込みできませんでした。配置は変更していません。」が表示される
- [x] 編集配置と3Dモデルが読み込み前から変化しない
- [x] 通知後も操作を続けられる

確認後はゲームを終了し、テストファイルを外して退避したファイルを戻します。
